# UK InfoTech

UK InfoTech is a modern technology website providing IT consulting and professional digital services.

## Features

- Modern and responsive user interface
- Attractive light and dark modes
- Interactive animations and technology-inspired design
- Paid IT consultation request form
- Email notifications for consultation requests using EmailJS
- Responsive layout for desktop, tablet, and mobile devices

## Technologies Used

- React
- JavaScript
- HTML and CSS
- EmailJS
- Vercel for deployment

## Email Consultation System

Users can submit their consultation requirements through the website. The form uses EmailJS to send request details to the configured recipient email address.

## Deployment

The website is hosted on Vercel, with the source code maintained in GitHub.
